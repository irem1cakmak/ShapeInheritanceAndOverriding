# Shape Inheritance and Overriding (Java OOP)

##  Project Description
This project demonstrates the use of Object-Oriented Programming (OOP) concepts in Java, specifically **inheritance** and **method overriding**.

A base class `Shape` is created, and derived classes `Circle`, `Rectangle`, and `Square` extend it. Each shape calculates its own **area** and **perimeter** using overridden methods.

Technologies Used
- Java
- IntelliJ IDEA
- Object-Oriented Programming (OOP)
